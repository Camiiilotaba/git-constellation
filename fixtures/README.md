# Simulated demo data

`demo.json` is a fictional, committed fixture. It requires no credentials and is never fetched from GitHub. Every day from **2025-11-01 to 2026-10-31**, inclusive, is explicitly present. The dates remain fixed so visual comparisons are reproducible. Live mode determines its period dynamically (a rolling year in UTC) and does not use this fixture; see `../docs/phase-2.md`.

The PHP normalizer accepts unsorted days, validates dates in UTC, and emits days **sorted by date**. Missing, duplicate, invalid, and out-of-period days are rejected rather than interpreted as zeros. Counts and their sum must fit JavaScript's safe integer range, from `0` to `9007199254740991`. A calendar contains at most 366 days.

Totals, active days, and longest streak are calculated from the daily fixture, not hardcoded as display metrics. An active day has at least one contribution; a streak consists of consecutive active calendar days within the inclusive fixture period. No streak extends beyond the available period. PRs and reviews are explicitly simulated public-scope examples, independent of daily contribution totals. Either can be `null` when unavailable. Demo output always declares `mode: "demo"`, `privateContributions: "excluded"` and `source: null`; it makes no claim about private GitHub activity.

Language ranking counts how many public repositories contain each detected language, including secondary languages. Forks and archived repositories are excluded. Each language counts only once per repository. Ties use ascending language name, and the result contains at most five languages. The fixture includes fork and archived examples to exercise exclusion. Repository byte size, usage recency, and user proficiency are not measured. The ranking describes this simulated repository collection only.

PHP hands daily values to the TypeScript renderer rather than calculating star positions. The agreed visual transform groups days by UTC Monday weeks, includes partial first and last weeks, places each point at its group's true time midpoint, and uses `sqrt(weekly count / maximum weekly count)` for normalized weekly height (zero when the entire period has no activity). All main-constellation positions come from the unchanged daily fixture. Faint dashed ornamental branches carry no counts and never alter the measured data series.

The fixture's `provenance` and repository metadata are used only as simulation input; neither is included in `build/data.json`. The fixture itself keeps its original input shape (it was written for Phase 1 and is unchanged); the output in `build/data.json` is `schemaVersion` 3 (`period.kind: last-year`, `granularity: week`), documented in `../docs/phase-2.md`. Profile identity, role, stack, colors, and default output path come from `config/demo.json` and can be replaced via `--config`.
