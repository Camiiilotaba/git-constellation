# Original provisional artwork

`space.svg` is original, text-free vector artwork for Git Constellation, distributed under the project MIT license. It reconstructs the spatial composition using independent SVG layers; the supplied design reference is not embedded, traced into an image, or used as a background.

The background includes a fixed decorative star field and nebula, a shaded planet, distant terrain, foreground rocks, and a seated developer. Surface shelves and flattened cloud bands are clipped to the planetary ellipse. Fixed SVG turbulence seeds add subtle relief and broken atmospheric texture; these layers are decorative and contain no contribution data. The developer uses curved silhouette, clothing, limb and laptop layers, with a foreground ledge supporting the seated posture.

All artwork is static, self-contained, and uses the existing dark cyan/teal palette. No external images, fonts, scripts, dependencies, or network requests are required. Profile text, metrics and the data-driven constellation belong to the renderer and are not included here. This remains provisional vector artwork rather than a photographic or painted reproduction of the reference.
